# 📖 About the Project

FitFusion is a modern fitness tracking application built using **Flutter** and **Firebase**, designed to help users manage their health and fitness journey from a single platform.

The application enables users to track workouts, monitor daily goals, analyze progress through interactive charts, maintain healthy habits, and receive AI-powered fitness guidance—all within a clean and responsive Material 3 interface.

This project was built to strengthen practical skills in Flutter development, state management, Firebase integration, responsive UI design, and clean architecture.

# 🚀 Getting Started

## Prerequisites

* Flutter SDK
* Android Studio or VS Code
* Firebase Project
* Android SDK

---

## Installation

Clone the repository

```bash
git clone https://github.com/rkzzzz008/FItFusion.git
```

Navigate into the project

```bash
cd FitFusion
```

Install dependencies

```bash
flutter pub get
```

Configure Firebase

```bash
flutterfire configure
```

Run the application

```bash
flutter run
```
